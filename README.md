## Running & Compiling from Source
> This section is only for developers wanting to modify or debug BananaPour

BananaPour runs on the [Godot Engine](https://godotengine.org/) and [C#](https://dotnet.microsoft.com/en-us/languages/csharp). This means you'll need a .NET supported version of the Godot Editor to open the project and make changes. If you don't have the C# enabled engine installed, [download here](https://godotengine.org/download/) and follow the [Godot C# setup](https://docs.godotengine.org/en/stable/tutorials/scripting/c_sharp/c_sharp_basics.html#introduction) guide.
